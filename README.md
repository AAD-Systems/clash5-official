## 🎮 Sobre o Jogo
**CLASH 5** é um jogo de tiro tático em terceira pessoa (TPS) focado em partidas rápidas de 5v5. Escolha seu Operador, libere o poder da **Ressonância** e domine a arena. Mas lembre-se: **toda magia cobra um preço brutal.**

## ⚙️ Funcionalidades (MVP)
- [x] Movimentação TPS Mobile (Joystick + Auto-Shoot).
- [x] Sistema de Habilidades com "Preço" (Ex: O Espectro perde a mira ao usar o Domo).
- [x] Multiplayer via Photon (5v5 em tempo real).
- [x] Integração com o Bot Oficial do Discord (Matchmaking, Stats e Playtest).

## 🤖 O Bot (C5 Core)
O jogo possui um sistema de comunidade integrado via Discord:
- `/lfg`: Cria uma sala de voz para times.
- `/stats`: Puxa o K/D e Rank do jogador direto do Banco de Dados.
- `/claim-key`: Distribui chaves de acesso ao Alpha.

## 🛠️ Como rodar o projeto (Para Devs)
1. Clone o repositório.
2. Abra na Unity 2022.3 LTS (URP).
3. Importe o pacote do Photon Fusion.
4. Rode o script `NetworkManager` na cena principal.
